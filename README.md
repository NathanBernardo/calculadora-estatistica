# Calculadora Estatística

Aplicação em Python com interface gráfica para análise estatística de dados.

## 🚀 Funcionalidades
- Média
- Mediana
- Moda (amodal, unimodal, bimodal…)
- Variância
- Desvio padrão
- Coeficiente de variação
- Tabela de frequência

## 🛠 Tecnologias
- Python
- PyQt5
